## SEO bookmarklets

`seo bookmarklets.html` is a broader set of SEO bookmarklets and tool shortcuts for auditing the page you're on. Import it via your browser's bookmark manager; it is added as a new folder alongside your existing bookmarks.

- **Pagespeed:** PageSpeed Insights, GTmetrix, WebPageTest, CrUX Vis, live Core Web Vitals overlay
- **Google SERP:** site: index check, SERP link scraper, search by location, Safe Browsing check
- **Ahrefs / alternatives:** Ahrefs, Majestic, Similarweb, Sistrix and Semrush for the current domain or URL
- **WM:** Wayback Machine for the domain or page
- **Rich results:** Rich Results Test, Schema Markup Validator, microdata inspector
- **Duplicerat:** duplicate-content checks on selected text, Siteliner
- **On-page:** JS on/off side-by-side, robots.txt parser, broken links, heading highlighter, rendering tests, images to alt text
- **Links on page:** highlight follow/nofollow, list outbound links
- **Store rating:** Google store rating lookup

Ahrefs, Sistrix and Semrush require an account.
